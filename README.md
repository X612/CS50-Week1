# CS50 Week 1

My solutions for **Week 1** of **Harvard's CS50x: Introduction to Computer Science**.

## 📚 About

This repository contains my solutions to the Week 1 problem set. The programs are written in **C** and cover the fundamentals of programming, including variables, conditionals, loops, functions, and algorithms.

## 📂 Contents

- **Hello** – A simple introduction to C and user input.
- **Mario (More)** – Prints a double half-pyramid using loops.
- **Credit** – Validates credit card numbers using the Luhn algorithm and identifies the card issuer.

## 🛠️ Language

- C

Harvard CS50x – Introduction to Computer Science
